```text
• 底层（局部）： 颗粒较细、token 数量较多，负责编码精细的局部信息（如纹理、发丝、边缘）。
  底层在量化时以顶层信息为条件，使细节生成与全局结构保持一致。​
• 解码器： 综合顶层与底层两套离散表示，共同重建出高分辨率图像。​
此外，每一层各自配一个独立的自回归先验模型，用于生成阶段分层采样。​




训练过程​
与 VQ-VAE 一样，VQ-VAE-2 也分两个阶段：先训分层自编码器，再训各层的自回归先验。​
• 第一阶段——训练分层自编码器与码本： 让图像经"编码 → 顶层/底层两级量化 → 解码"后重建自
  身，以重建损失训练编码器、解码器与两层码本。量化不可导的问题仍沿用直通估计处理。训练完
  成后，得到一个能把图像编码为"顶层 + 底层"两套 token、并能据此还原图像的分层 tokenizer。​
• 第二阶段——分层训练自回归先验： 冻结自编码器，把训练图像转成两层 token 序列，分别训练两
  个自回归先验：一个先验学习顶层 token 的分布（无条件，纯粹生成全局骨架）；另一个先验学习
  底层 token 的分布，且以顶层 token 为条件（在已知全局结构的前提下补充细节）。​
生成过程​
生成沿"先生成全局、再补充细节、最后解码"的层级顺序展开。​
• 生成顶层 token： 先用顶层先验自回归地生成整张图的全局 token 序列，确定图像的整体结构。​
• 条件生成底层 token： 再用底层先验，以刚生成的顶层 token 为条件，自回归地生成底层细节
  token——细节的填充始终服从已确定的全局骨架，保证两者协调。​
• 解码还原： 将顶层与底层 token 一并查回码本向量、送入解码器，重建出最终的高分辨率图像。​
```
