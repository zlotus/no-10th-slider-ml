这张图用一辆自行车说明 CNN 的核心机制——特征的逐层抽象。CNN 由多层堆叠而成，图像逐
                层向前传播，每经过一层，提取到的特征就更抽象、感受野也更大。
       从下往上对应网络从浅层到深层：浅层（底部）只能提取最低级的局部特征——边缘、短线、圆
       弧，单看完全看不出是什么；中间层把这些低级特征组合成车轮、车架等更高级的局部结构；深
                   层（顶部）进一步组合，最终对应到"自行车"这个完整物体。
       这种"局部特征 → 逐层组合 → 整体语义"正是 CNN 的核心逻辑，也暴露了它的短板：每层的卷
       积核只覆盖局部感受野，全局信息必须靠堆叠足够多的层、层层传递才能获得。这也是为什么后
           来 Transformer（每个 token 第一层就能与全图交互）在大数据下能反超 CNN。
• Patch Tokenization： 将图像视为"patch 序列"的思想，为后来的 DiT（用 Transformer 替代 U-
   Net 做扩散）和自回归图像生成（把图像当 token 序列逐个预测）奠定了基础。​
• 扩展性（Scalability）： 展示了 Transformer 在视觉领域同样遵循"更大模型 + 更多数据 = 更好性
   能"的 Scaling Law。​
局限​
• 数据饥渴： 在中等规模数据集（如仅用 ImageNet-1k 训练）上，ViT 的表现不如同规模的 CNN，
   需要大规模数据或强数据增强才能发挥优势。​
• 计算成本高： 自注意力的二次复杂度使得处理高分辨率图像的计算成本很高。​
地位 & 影响​
ViT 的意义远超图像理解本身——它证明了 Transformer 可以作为视觉领域的通用骨干，从而打开了
视觉与语言共享统一架构的大门。​
这直接促成了 CLIP（视觉-语言对齐）、DiT（用 Transformer 替代 U-Net 做扩散模型骨干）、以及各
种自回归视觉生成模型（DALL·E 1、LlamaGen 等）。​
可以说，「图像可以被当作一串 token 来处理」这个思想，是后来从扩散模型走向自回归图像生成
（GPT-Image 路线）的核心前提。对扩散范式而言，ViT 提供了架构优化；对自回归范式而言，ViT 提
供了存在前提。​
