💡 重新定义了自回归的顺序，将「逐 token 预测」改为「逐尺度预测」；第一次全面超越
    DiT。​
简介​
VAR 提出了一种全新的自回归"顺序"定义：不再按光栅扫描逐 token 预测，而是按分辨率尺度从粗到
细预测（next-scale prediction，下一尺度预测）。先生成最低分辨率的 token map，再以其为基础
逐级生成更高分辨率的 token map，直至最高分辨率。这一改动既保留了图像的二维空间结构，又大
幅减少了生成步数，首次在 ImageNet 基准上全面超越 DiT。​




模型结构​
VAR 仍是"tokenizer + 自回归 Transformer"的整体框架，但 tokenizer 和预测目标都围绕"多尺度"重
新设计：​
• 多尺度 tokenizer： 不再把图像编码为单一分辨率的 token map，而是编码为一组从粗到细、分辨
   率递增的 token maps（如 1×1、2×2、4×4 … 直到最高分辨率）。粗尺度承载全局结构，细尺
   度承载局部细节。​
• 自回归 Transformer（按尺度展开）： 主体仍是 Transformer，但它自回归的单位是"一个完整的
   尺度"而非"一个 token"。预测某一尺度时，模型以此前所有更粗的尺度为条件，一次性并行生成当
   前尺度的全部 token。​
训练过程​
VAR 的训练目标从"预测下一个 token"改为"预测下一个尺度"，但仍是自回归式的条件预测。​
• 训练多尺度 VQ 自编码器（tokenizer）： 用多尺度 tokenizer 把每张训练图编码为一组由粗到细
   的 token maps，作为各尺度的监督目标。​
