• 训练 VAR Transformer，用于 next-scale prediction（逐尺度预测）： 训练 Transformer 在"已
  知前面所有粗尺度"的条件下，预测下一个（更细）尺度的全部 token。由于同一尺度内的 token
  可并行预测，训练效率较逐 token 方式更高；损失仍为对 token 的分类（负对数似然）。模型借此
  学会"如何从粗略轮廓逐级细化出完整图像"。​




生成过程​
生成沿"由粗到细、逐尺度生成"展开。​
 • 逐尺度生成： 从最低分辨率尺度起步，自回归地生成整张图的全局 token map；再以已生成的所
   有粗尺度为条件，依次生成更高分辨率的 token map，一级一级补充细节，直到最高分辨率。每个
   尺度内部的 token 一次性并行产出，因此总步数仅为尺度数量，远少于逐 token 方式。​
 • 解码还原： 将最终的多尺度 token 经 tokenizer 解码，还原为完整图像。​
核心贡献​
传统自回归把 2D 图像强行拉成 1D 序列，丢失了空间结构信息。VAR 保留了 2D 空间关系，用多尺度
层级替代了一维序列。首次在 ImageNet 基准上全面超越了 DiT，并验证了与 LLM 类似的 scaling
laws。​
局限​
 • 依赖专门的多尺度 tokenizer： 整套方法的效果与多尺度量化的设计强相关，tokenizer 的构建比单
   尺度方案更复杂。​
 • 主要在类别条件 / ImageNet 上验证： 原文以类别条件生成为主，向大规模开放域文生图的扩展仍
   需后续工作检验。​
地位与影响​
NeurIPS 2024 最佳论文。它重新定义了「自回归」在视觉领域应该怎么做，可能是这条路线上最重要
的范式革新。​
