```text
VAE 和它的损失函数
VAE 与 Autoencoder 的关键区别​
• 输出方式不同： Autoencoder 的编码器输出一个固定的潜在向量（一组确定的数字），VAE 的编
  码器输出的是一个概率分布的参数（均值 μ 和方差 σ），再从这个分布中采样得到潜在向量。​
• 训练目标不同： Autoencoder 只有重建损失（输出尽量接近输入）。VAE 在此基础上增加了 KL 散
  度损失，强制让编码器输出的分布接近标准正态分布，从而使潜在空间连续、平滑。​




 同样是「笑的程度」，普通 Autoencoder（中间）存一个固定值，VAE（右边）存一条概率分布——曲线的中心
（μ）表示笑的程度（越靠右越笑），胖瘦（σ）表示确定程度（越窄越确定、越宽越模糊）。比如大笑的男人中心靠
右且曲线窄，蒙娜丽莎中心居中且曲线宽（似笑非笑、模棱两可）。这就是两者的根本区别：VAE 编码器输出的是分
                         布参数，而非确定的数字。
```
