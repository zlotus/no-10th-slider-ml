核心发现是：只要 tokenizer 够好、数据质量够高，纯粹的 LLM 架构不需要任何修改就能做好图像生
成。直接复用了 LLM 的训练框架、推理优化（vLLM 等），实现了 3–4 倍的推理加速。​
局限​
• 质量受 tokenizer 上限制约： 生成质量高度依赖离散 tokenizer 的重建能力，tokenizer 成为整个
   系统的瓶颈。​
• 逐 token 生成仍偏慢： 即便有推理加速，标准自回归的串行生成相比扩散的并行去噪在长序列上仍
   有速度劣势。​
与 VAR 的关系​
VAR 证明了「换一种自回归顺序」可以超越扩散模型；LlamaGen 证明了「用最标准的 LLM 架构 + 标
准的 next-token prediction」也能超越扩散模型。两者从不同角度证实了自回归范式的潜力。​
地位与影响​
它是「自回归图像生成可以直接搭 LLM 便车」这个论点最有力的实证，为文本和图像的统一生成模型
（如 Emu3、Chameleon）提供了架构层面的信心。它也呼应了全文的大趋势——当图像被当作一
种"语言"来处理，所有模态便都在向 Transformer 这一统一架构收敛。​
核心贡献​
• 证明纯 LLM 架构无需修改即可超越扩散： 不加任何视觉归纳偏置，仅靠标准 Llama 架构 + 高质量
   tokenizer，在 ImageNet 256×256 上以 FID 2.18 超越 LDM 与 DiT。​
• 直接复用 LLM 生态： 训练框架与推理优化（如 vLLM）拿来即用，实现约 3–4 倍推理加速，工程
   成本大幅降低。​
