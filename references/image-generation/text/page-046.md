六、思考​
1. 模型不仅会越来越强，迭代速度也会越来越快，Agent 化的趋势也会越来越明显。​
   ◦ Agent 化趋势：gpt-image-2 支持先思考再行动、支持联网搜、生成完成后会自检纠错​
   ◦ 对开发者来说，很多原本属于工程的工作正在不可避免地贬值。​
2. 没有悲观的必要​
   ◦ 「最好的模型」不等于「最受欢迎的产品」，正如「最好的产品」「最佳的内容」往往不等于
      「最佳的销量 / 流量」。一方面，绝大多数普通用户并不追求顶尖资源，反而是「够用就
      行」，因此完全没有必要对模型的碾压感到悲观；另一方面，产品功能和使用体验仍起到非常
      关键的决定性作用（参考近半年大众从 claude code cli 到 codex 客户端的转向）​
3. 拥抱现实​
   a. 防守：传统软件传统功能的高度确定性、速度、隐私、成本、使用惯性等优势。​
   b. 耕耘：「强模型能力」和「用户对结果满意」之间的差距。​
   c. 进攻：有了模型能力作为支持，可以探索许多原来无法实现的产品功能，或者在模型难以取代
      的存量功能上借助模型能力进行优化；另外，有了 AI 提效，我们得以有机会真正实现软件开发
      的快速迭代 / 验证。​
4. 如何耕耘「强模型」和「用户满意」之间的差距​
