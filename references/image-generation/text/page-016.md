DDPM 的完整流程，上半部分（红色）：Forward Diffusion Process — 前向加噪。q(xₜ|x₀) 这个公式表示你可以从
  原图 x₀ 直接一步跳到任意时间步 t 的噪声图，不用真的一步步加；右上角的公式说整个前向过程是一条马尔可夫
链，每一步的加噪只依赖上一步，走到最后 T 步时，结果近似于标准高斯分布 N(0, I)；下半部分（蓝色）：Reverse
Diffusion Process — 反向去噪。每一步的去噪操作是：把当前噪声图 xₜ 和时间步 t 丢给去噪网络 ε_θ(xₜ, t)（最底部
那个 U-Net 结构的示意图）网络预测出当前的噪声。然后用预测结果算出 x_{t-1} 的均值 μ_θ 和方差 Σ_θ，再加上一
                 点随机噪声 ε 采样得到 x_{t-1}。公式就是 x̃_{t-1} = μ_θ(xₜ, t) + √Σ_θ(xₜ, t) · ε。
去噪网络架构​
扩散模型的去噪网络有两种主流架构选择：​
• U-Net：DDPM 原论文采用的架构。对称的编码器-解码器结构，编码器逐层压缩提取抽象特征，解
  码器逐层放大还原分辨率，两侧通过跳跃连接（skip connections）直接传递信息，使输出同时保
  留深层语义和浅层细节。输入输出尺寸相同，天然适合"输入噪声图、输出预测噪声"的去噪任务。
  从 DDPM 到 Stable Diffusion，U-Net 一直是扩散模型的默认骨干。
  https://arxiv.org/abs/1505.04597​
• Transformer（DiT）：后来 DiT（Diffusion Transformer）将骨干替换为 Transformer——把噪
  声图像切成 patch 序列，用注意力机制让每个 patch 从第一层就能与所有其他 patch 直接交互，全
  局信息捕捉效率更高，且扩展性（scaling）更优。Sora 等新一代模型已采用此架构。
  https://arxiv.org/abs/2212.09748​
