• 模型有两个编码器：一个图像编码器（ResNet 或 ViT），一个文本编码器（Transformer）。每
   个编码器把各自的输入压缩成一个固定长度的向量（比如 512 维）。​
• 训练目标就是对比学习：一个 batch 里有 N 个图文对，正确配对的图文向量要拉近（余弦相似度
   → 1），其余 N²−N 个错误配对要推远（余弦相似度 → 0）。训练完成后，两个编码器就学会了把
   语义相同的图和文映射到同一张地图上的相邻位置。​
CLIP 的使用（文生图场景）​
• CLIP 训练完之后，在文生图场景中只用它的文本编码器。​
• 流程：用户输入 prompt → CLIP 文本编码器将其编码为一个 512 维向量 → 这个向量作为条件信号
   注入生成模型（如扩散模型），在每一步去噪过程中引导生成方向。​
• 注意：CLIP 本身不生成图像，也不担任生图模型的核心网络结构。它是一个工具，只负责"把人话
   翻译成生成模型能理解的坐标"，是文生图 pipeline 中的语义翻译层。​
核心贡献​
• 实现了文本与图像之间的大规模语义对齐，成为所有「文本到图像」系统的语义基础设施。​
• 之前的 GAN 和 VAE 只能做无条件生成或粗粒度类别控制，CLIP 让「用自然语言描述来引导生成」
   成为可能。​
局限性​
• 组合理解能力弱： CLIP 对属性绑定（"黄色的小猫的杯子和白色的花"vs"白色的小猫和红色的
   花"）和空间关系的理解较弱，基于 CLIP 引导的生成模型也继承了这一缺陷。​
地位 & 影响​
CLIP 是连接视觉和语言两大模态的桥梁，它的出现深刻改变了文本到图像生成的研究路径。​
在扩散范式中，Stable Diffusion 使用 CLIP 的文本编码器作为条件输入。 DALL·E 2 / unCLIP 则以
CLIP 为核心构建。​

三、扩散范式​
扩散模型的核心思想是：前向过程逐步向图像加高斯噪声直到变成纯噪声，反向过程训练一个网络逐
步去噪。破坏容易，重建难，但如果把破坏过程拆成足够多的小步，每一步的逆过程就变得可学习。​
