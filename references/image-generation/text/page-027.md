11   注意右上和右下是两张不同的柯基图：右上是训练时用的真实配对图，右下是模型实际生成的结果。​

训练过程​
DALL·E 2 的训练围绕 Prior 和 Decoder 两个可学习组件展开，CLIP 全程冻结、仅提供嵌入。​
• 准备工作（CLIP 冻结）： 复用预训练好的 CLIP。对每个图文对，CLIP 文本编码器给出文本嵌入，
  CLIP 图像编码器给出对应的图像嵌入——后者将作为 Prior 的训练目标和 Decoder 的训练条件。​
• 训练 Prior（文本嵌入 → 图像嵌入）： 输入 CLIP 文本嵌入，让 Prior 预测同一图文对的 CLIP 图像
  嵌入，以真实图像嵌入为监督目标。如此训练后，Prior 学会了在 CLIP 空间内完成"从文字落点挪
  到图片落点"的跨越。​
• 训练 Decoder（图像嵌入 → 图像）： 这是一个标准的条件扩散模型训练。取一张真图，用 CLIP
  图像编码器算出它的图像嵌入作为条件，按 DDPM 的方式对真图加噪，让扩散网络在该图像嵌入的
  条件下预测所加噪声，以 MSE 反向传播。训练目标是：给定一个 CLIP 图像嵌入，能还原出语义匹
  配的图像。​
生成过程​
训练完成后，文本到图像的生成沿"文本 → 文本嵌入 → 图像嵌入 → 图像"的链条逐级展开。​
• 文本编码： 用户输入 prompt，经冻结的 CLIP 文本编码器编码为文本嵌入。​
• Prior 映射： Prior 接收文本嵌入，生成一个对应的 CLIP 图像嵌入——相当于在 CLIP 语义地图
  上，从"文字所在的位置"跳到"目标图像应在的位置"。​
• Decoder 解码： 扩散解码器以该图像嵌入为条件，从纯噪声开始逐步去噪，生成一张较低分辨率
  的图像。​
• 上采样： 再经上采样扩散模型提升至 1024×1024，得到最终结果。​
值得一提的是，由于生成必经"CLIP 图像嵌入"这一中间表示，若直接对一张真实图像用 CLIP 图像编码
器取嵌入、再交给 Decoder 重新生成，即可得到语义相近但视觉不同的"图像变体"；这也使基于文本
的图像编辑变得自然。​
核心贡献​
• CLIP 嵌入作为中间表示： 通过在 CLIP 的联合嵌入空间中操作，模型天然继承了 CLIP 强大的语义
  理解能力，文本-图像的语义对齐质量大幅提升。​
• Prior + Decoder 两阶段架构： Prior 负责文本语义到视觉语义的映射（文本嵌入 → 图像嵌入），
  Decoder 负责从视觉语义到像素的生成（图像嵌入 → 图像）。这种分解使得各阶段可以独立优
  化。​
• 图像变体和编辑： 由于生成过程经过 CLIP 图像嵌入，模型天然支持"给定一张图像，生成其语义相
  似但视觉不同的变体"以及基于文本的图像编辑。​
• 产品级质量： DALL·E 2 是最早引起公众广泛关注的 AI 生图产品之一，其生成质量和多样性震撼了
  业界。​
