• 逐 token 自回归采样： 用训练好的 PixelCNN 先验，从头逐个生成 token——根据已生成的 token
   预测下一个 token 的分布并采样，直到凑齐一整张图所需的 token 网格（如 32×32）。相比逐像
   素，token 数量少了一两个数量级，生成步数大幅减少。​
• 解码还原： 将生成好的 token 序列按编号查回对应的码本向量，送入解码器，一步还原成完整图
   像。​
核心贡献​
把自回归模型从「逐像素预测」解放到了「逐 token 预测」。这是 VAE 和自回归模型的桥梁——借用
VAE 的编码解码框架，但用离散量化替代连续采样。​
局限​
• 单层量化，全局与局部难兼顾： 原始 VQ-VAE 只有单一尺度的码本，难以同时刻画图像的全局结构
   与精细细节，生成质量与同期 GAN 仍有差距（这一点由后续的 VQ-VAE-2 通过多尺度层级量化改
   进）。​
• 码本相关问题： 训练中可能出现码本利用率低（大量码字几乎不被使用）等问题，影响表征效率。​
地位与影响​
后续几乎所有自回归图像生成工作的 tokenizer 都源自 VQ-VAE 的思想。没有它就没有后面的
VQGAN、DALL·E 1、LlamaGen。其"离散视觉词典"的理念，也是日后将图像纳入统一多模态序列、
与文本 token 一同建模的关键前提。​

3. VQ-VAE-2 (2019) ​
 Generating Diverse High-Fidelity Images with VQ-VAE-2 — Razavi et al. (DeepMind)
 (2019)https://arxiv.org/abs/1906.00446​
 💡 在 VQ-VAE 基础上引入分层设计，大幅提升生成质量。​
简介​
VQ-VAE-2 在 VQ-VAE 的基础上引入多尺度层级结构来提升生成质量。其核心判断是：单层量化难以同
时兼顾图像的全局结构与局部细节——颗粒太粗则丢失细节，太细则 token 过多。VQ-VAE-2 改用两层
量化（顶层捕捉全局结构，底层捕捉局部细节），并为每一层分别训练一个自回归先验，从而在保持
token 数量可控的同时大幅提升保真度。​
模型结构​
VQ-VAE-2 把 VQ-VAE 的"单层量化"扩展为"分层量化"，整体仍是"编码 → 量化 → 解码"的框架，但量
化分为两个尺度：​
 • 顶层（全局）： 颗粒较粗、token 数量较少，负责编码图像的整体结构与全局语义（如人脸朝向、
   物体大致形状与布局）。​
