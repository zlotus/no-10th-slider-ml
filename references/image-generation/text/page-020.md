简介​
GLIDE 是 OpenAI 探索文本引导扩散模型的重要里程碑。在它之前，Beat GANs 提出的 Classifier
Guidance 虽然能引导生成，但依赖一个在噪声数据上额外训练的分类器，且天然只适配类别标签，难
以扩展到自由文本。GLIDE 系统性地验证了一种更优雅的替代方案——Classifier-Free Guidance
（CFG），无需任何外部分类器，引导能力完全内化于扩散模型自身，并将其与 cross-attention 文本
注入结合，确立了文本引导扩散模型的标准范式。​




                              GLIDE 架构
网络结构​
GLIDE 的主体是一个扩散模型，骨干为 U-Net。文本部分由一个 Transformer 文本编码器处理：将
prompt 编码为一串 token 嵌入，再通过 cross-attention 注入 U-Net 的各层，使去噪网络在每一步都
能"读到"完整的文本语义，而非仅在起始处接收一次条件信号。整个模型规模为 35 亿参数；生成在
64×64 像素空间进行，再由一个独立的上采样扩散模型提升至 256×256。​
训练过程​
GLIDE 的训练在标准扩散模型（DDPM）的去噪目标之上，增加了文本条件与 Classifier-Free
Guidance 的关键设计。需要强调的是，整个过程只训练一个去噪网络，不涉及任何额外的分类器。​
• 输入构成： 网络的输入由三部分组成——加噪图像 xₜ、时间步 t、以及经文本编码器编码后的文本
   嵌入。任务仍是预测该步所加的噪声，损失函数为预测噪声与真实噪声之间的 MSE。​
• 条件随机丢弃（CFG 的核心）： 训练时以一定比例（约 10%–20%）随机将文本条件替换为一个空
   的占位符，让网络在"无文本"状态下完成去噪。如此一来，同一个网络同时学会了两种模式——有
   文本条件的去噪与无条件的去噪。这正是 "Classifier-Free" 的由来：引导能力不再来自外部分类
   器，而是由网络自身的"有条件 / 无条件"两种预测之差提供。​
• cross-attention 文本注入： 文本嵌入通过 cross-attention 参与 U-Net 每一层的计算，使文本语义
   在整个去噪过程中持续发挥引导作用。​
生成过程​
训练完成后，GLIDE 通过 Classifier-Free Guidance 实现高质量的文本引导采样。​
• 双路预测： 在每一个去噪步骤，让同一个网络对当前噪声图做两次预测——一次输入文本嵌入，得
   到有条件预测；一次输入空占位符，得到无条件预测。​
